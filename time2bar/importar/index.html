Del tracking a Time2Bar

Instala el skill

Descarga time2bar-import-skill.zip y súbelo desde la sección Skills de tu asistente.

Pega o adjunta tu historial

Puedes usar notas, CSV, una hoja de cálculo exportada o texto. Revisa los avisos; el skill no debe inventar fechas ni valores.

Guarda el JSON

Pide “convierte esto para Time2Bar” y descarga o copia el objeto JSON resultante.

Revisa e importa

En Time2Bar abre Ajustes → Datos → Importar entrenamientos. Elige el archivo, revisa la vista previa y confirma.

Privacidad

Los CSV y JSON se procesan localmente dentro de Time2Bar. Si utilizas ChatGPT, Codex o Claude para convertir tu tracking, el contenido que envíes será tratado por ese proveedor según su configuración y política. No incluyas datos médicos, contraseñas ni información personal innecesaria.
